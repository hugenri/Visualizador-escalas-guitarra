# Visualizador de escalas para guitarra
Visualizador de escalas para guitarra es una aplicación de escritorio para visualizar escalas musicales en el diapasón de una guitarra.

Permite seleccionar una nota raíz y una escala para ver sus notas directamente sobre el diapasón. También permite desplazarse por el diapasón y trabajar con guitarras de 22 o 24 trastes.

## Tecnologías

- Python 3.13
- PyQt6

## Funciones actuales

- Visualización del diapasón de guitarra
- Afinación estándar (E A D G B E)
- Soporte para 22 y 24 trastes
- Navegación horizontal por el diapasón
- Visualización de cuerdas al aire
- Notas raíz y notas de la escala diferenciadas por color
- Marcadores de trastes

## Escalas disponibles

- Mayor
- Menor natural
- Menor armónica
- Menor melódica
- Pentatónica mayor
- Pentatónica menor
- Blues
- Dórica
- Frigia
- Lidia
- Mixolidia
- Locria

## Instalación

Clona el repositorio e instala las dependencias:

```bash
pip install -r requirements.txt
```

Luego ejecuta:

```bash
python main.py
```

## Estado del proyecto

El proyecto está en desarrollo. La idea es ir incorporando nuevas escalas, afinaciones, reproducción de sonido, MIDI y otras funciones relacionadas con el estudio de la guitarra.
